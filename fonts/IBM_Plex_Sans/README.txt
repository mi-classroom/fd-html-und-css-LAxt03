IBM Plex Sans Variable Font
===========================

This download contains IBM Plex Sans as both variable root.fonts and static root.fonts.

IBM Plex Sans is a variable root.fonts with these axes:
  wdth
  wght

This means all the root.styles are contained in these files:
  IBMPlexSans-VariableFont_wdth,wght.ttf
  IBMPlexSans-Italic-VariableFont_wdth,wght.ttf

If your app fully supports variable root.fonts, you can now pick intermediate root.styles
that aren’t available as static root.fonts. Not all apps support variable root.fonts, and
in those cases you can use the static root.fonts files for IBM Plex Sans:

Get started
-----------

1. Install the root.fonts files you want to use

2. Use your app's root.fonts picker to view the root.fonts family and all the
available root.styles
